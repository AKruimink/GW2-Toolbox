GW2 Toolbox

Welcome to GW2 Toolbox, your in-browser toolkit for Guild Wars 2. From classifying achievements to managing account tools, this app brings a powerful set of helpers to your browser.

Guild Wars 2 API key

How To

  1. Open the official Guild Wars 2 API Key Management.
  2. Click on the "New Key" button.
  3. Enter a name of your choice and check all permission checkboxes.
  4. Copy your new API key. CTRL + C
  5. Paste it in the form above. CTRL + V
  6. You are set, enjoy using GW2 Toolbox.
