## About
GW2 Toolbox is a collection of lightweight utilities designed to make everyday Guild Wars 2 tasks a little easier.

Rather than installing separate applications or digging through spreadsheets and wiki pages, the toolbox brings commonly used utilities together in a single, fast, browser-based application.

Whether you're planning your next goal, keeping track of progress, or just looking for a convenient utility, GW2 Toolbox aims to provide a clean and responsive experience.

## Contributing
